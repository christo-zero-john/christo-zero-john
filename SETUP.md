# Profile maintenance

This directory is the source for [Christo John's GitHub profile](https://github.com/christo-zero-john).

## Files

- `README.md` — the public-facing profile
- `assets/hero.svg` and `assets/footer.svg` — graphic identity
- `assets/engineering-stats.svg` — public/private repository footprint
- `assets/contribution-grid.svg` — optional aggregate contribution chart generated by the script (not currently embedded in the README)
- `scripts/update-stats.mjs` — GitHub GraphQL aggregate data and SVG renderer
- `.github/workflows/refresh-profile-stats.yml` — daily and manual data refresh

## Private-inclusive repository statistics

The repository card counts public and private repositories by querying the account with an authenticated GitHub token. It never publishes names, URLs, commit messages, or contents from private repositories.

1. In GitHub settings, create a personal access token for `christo-zero-john` with access to the repositories you want counted. Prefer the least-privileged token that works. **Classic tokens with `repo` scope grant broad read/write access**, so treat them as high-impact credentials and use short expiration periods.
2. Add the token as the repository Actions secret `GH_STATS_TOKEN`.
3. In Actions, run **Refresh private-safe GitHub profile metrics** on the `main` branch.
4. The workflow commits refreshed SVG assets to the profile repository. It also runs automatically once a day.

The workflow expects access to at least 32 owned private repositories (the verified 31 October 2026 baseline). Update `MIN_EXPECTED_PRIVATE_REPOS` only when that baseline legitimately changes.

To see private contributions in GitHub's native contribution calendar, independently enable **Contribution settings → Private contributions** on your GitHub profile.

## Local check

```bash
node --check scripts/update-stats.mjs
node scripts/update-stats.mjs --snapshot
```

The snapshot command restores the verified baseline instead of fetching live statistics. Do not run it if you wish to retain freshly synced contribution data.

## Design notes

The visual identity uses dark graphite, warm white, and a single lime accent. The custom SVGs include subtle animation with a reduced-motion fallback. Standard GitHub Markdown and HTML tables provide the content layout; no external CSS or JavaScript runs in the README.

The profile remains intentionally selective. Public links point only to public material. The client and internal engineering descriptions are generalized.

## Credential safety

Never commit any token. Keep personal access tokens in GitHub Actions secrets and rotate them before expiration. Avoid triggering privileged statistics workflows from untrusted pull requests.
