## How to interpret the totals

1. **Attributed commits** = author email matched + co-author email matched + explicitly approved agent-only SHAs. Git author names alone and agents in upstream forks are excluded.
2. **Total LOC changed** = sum of Git `--numstat` added + deleted text lines across every attributed commit. This includes docs, configs, lockfiles, generated text and repeated edits; it is not current codebase size or unique lines written.
3. **Code-classified LOC** uses filename extensions. It is an approximation and excludes many unrecognized formats.
4. **Renames** use Git rename detection; binary changes have no meaningful line count.
5. **Merge diffs** are compared with their first parent. Their changes can overlap with commits on the merged branch, so cumulative changed-line counts are not unique surviving lines.
6. **Forks** are included when available. Repo-level totals count the same SHA in two different repositories twice; the **unique attributed Git SHAs** and **unique LOC changed** fields deduplicate matching SHAs across repositories.
7. **Coverage scope:** All available refs in each cloned repository (branches, tags, and refs advertised by GitHub); each SHA once per repository. Verified author/coauthor email matches qualify. Unrelated upstream commits and third-party agent co-authorship do not qualify. Agent-only SHA approvals must be explicit in AUDIT_APPROVED_AGENT_COMMITS.
8. Email aliases are automatically discovered from GitHub account-linked indexed commits and accessible verified-email APIs; name-only matches are NEVER included in verified totals.
9. Commits on local branches never pushed to GitHub, deleted repositories, inaccessible private repositories, and contributions with no identifiable Git identity cannot be recovered as exact lifetime data.
10. **Private-repository names and links** are masked in public Markdown/JSON by default. The combined totals still include scanned private repositories.
11. GitHub's PR/issue/search indices and current follower/star counts are separate from Git commit history.

**Note:** The per-year, per-month, and per-language history tables use repository/SHA occurrences; they may include duplicate Git SHAs when a repository is forked or mirrored.
