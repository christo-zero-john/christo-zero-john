## Historical changed lines by filename

This classifies changed filenames using the official GitHub Linguist language definitions for filename and extension. Ambiguous classifications are kept separate. Historical blobs are not fed through Linguist's full content parser. Documentation/configuration rows are part of the overall LOC total but not the code-only subset.
